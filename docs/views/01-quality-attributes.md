# Атрибуты качества сервиса лчиного кабинета с агрегацией данных 

## От драйверов к атрибутам

Драйверы сервиса личного кабинета:

- **D1** — всплески нагрузок на чтение;
- **D2** — нестабильность смежных систем;
- **D3** — компромисс между скоростью отклика и актуальностью данных;
- **D4** — работа c персональными данными.

Приоритетные атрибуты: 

| Атрибут | Тип | Где в ISO 25010 | Какой драйвер закрывает |
|---------|-----|-----------------|--------------------------|
| Производительность | runtime | Performance Efficiency | D3 |
| Масштабируемость | runtime | Performance Efficiency | D1 |
| Отказоустойчивость / Доступность | runtime | Reliability → Availability / Fault tolerance | D2 |
| Безопасность | runtime | Security | D4 |
