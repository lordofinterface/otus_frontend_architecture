# Дерево полезности

```
Полезность
├── Отказоустойчивость
│   └── Изоляция сбоев источников
│       └── S1. Падение одного источника данных не влияет на показ других данных (H, H)
├── Производительность
│   ├── Быстрая загрузка
│   │   └── S1. Агрегация данных → ответ быстрее 500 мс ........................ (H, M)
├── Масштабируемость
│   └── Поглощение всплесков трафика
│       └── S3. Пик запросов → автомасштабирование чтений ...................... (H, M)
└── Безопасность
    └── Защита публичного эндпоинта
        └── S4. Брутфорс/парсинг → Rate limiting и блокировка .................. (H, L)
```

## Сценарии

### S1. Изоляция сбоя источников — (H, M)

Смежный севрис-источник перестает отвечать иди возвращает ошибку. Личный кабинет остается доступен. Отсекаем запрос, отдаем страницу со здоровыми блоками данных, на месте "упавших" данных показываем сообщение об ошибке, заглушку, кеш или ничего, зависит отконтекста (применяем Circuit Breaker, graceful degradation).

Мера: 100% сбоев единичных источников изолируются. Общий статус ответа агрегатора для клиента остается успешным. Деградация общего времени ответа Личного кабинета ограничена строгим таймаутом.

### S2. Быстрая загрузка — (H, M)

При открытии ЛК при штатной нагрузке агрегатор данных собирает данные ассинхронно, а редко меняющиеся данные отдаются из кэша.

Мера: p99 времени ответа на запрос не превышает 500 мс

### S3. Поглощение всплесков трафика — (H, M)

При пиковой нагрузке балансировщик распределяет трафик, инфраструктура автоматически масштабирует поды на чтение, а большая часть данных отдается через кэш 

Мера: Система выдерживает рост трафика до 500 RPS; при этом доля 5xx ошибок составляет 0.01%, p99 времени ответа не превышает 800 мс

### S4. Защита публичного эндпоинта — (M, L)

При массовых запросах с невалидными и перебираемыми токенами система првоеряет токен, отбрасывает невалидные и временно блокирует подозрительный IP.

Мера: 100% запросов без валидного токена отклонены. При превышении 50 невалидных попыток в минуту IP-адрес автоматически блокируется на 15 минут. Каждый отказ попадает в лог аудита.
